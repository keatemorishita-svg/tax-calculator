# 个人所得税计算器

基于 2019 年新个税法的中国个人所得税估算工具，支持工资薪金月度预扣税计算和年终奖计税方案优化。

## 功能

- **工资薪金** — 12 个月逐月预扣个税模拟，支持社保公积金、专项附加扣除
- **年终奖优化** — 对比「单独计税」与「合并计税」两种方案，自动推荐省税路径
- **社保基数上下限** — 可配置缴费基数封顶/保底线，匹配各地政策
- **localStorage 持久化** — 工资数据、扣除项、历史方案自动保存

## 专项附加扣除支持

| 扣除项 | 标准 |
|--------|------|
| 子女教育 | 2,000 元/月/人 |
| 继续教育（学历） | 400 元/月 |
| 继续教育（职业资格） | 3,600 元/年 |
| 住房贷款利息 | 1,000 元/月 |
| 住房租金 | 800~1,500 元/月（按城市等级） |
| 赡养老人 | 1,500~3,000 元/月 |
| 3 岁以下婴幼儿照护 | 2,000 元/月/人 |
| 大病医疗 | 年度超 15,000 元部分，上限 80,000 元（汇算清缴） |

## 运行

纯静态页面，任意 HTTP 服务器即可：

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve .

# 也可以直接双击 index.html 打开（ES module 需要 HTTP 服务）
```

浏览器打开 `http://127.0.0.1:8080`。

> 注意：由于使用了 ES modules (`type="module"`)，需要 HTTP 服务器访问，直接 `file://` 协议会导致 CORS 错误。
